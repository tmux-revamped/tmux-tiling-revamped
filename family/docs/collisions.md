## Root key table

The doctor does not yet read the root table, because neither member declares its
root bindings through a key option. Read from the sources directly:

- `tmux-pain-control-revamped` binds `C-h`, `C-j`, `C-k`, `C-l` and `C-\`.
- `tmux-scroll-revamped` binds `WheelUpPane`, `WheelDownPane`, `WheelUpStatus` and `WheelDownStatus`.

Both write the root table unconditionally, so the last plugin sourced wins and
behavior depends on line order in the config.
